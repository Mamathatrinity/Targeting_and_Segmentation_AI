## 🚀 How to Use (Examples)

### **Option 1: UI Testing Only (Current Behavior)**
```bash
python main.py --url "https://example.com"
# or
python main.py --url "https://example.com" --mode ui_only
```

### **Option 2: Full Stack Testing (UI + API + Data)**
```bash
python main.py \
  --url "https://example.com" \
  --api "https://api.example.com" \
  --data "postgresql://localhost/mydb" \
  --mode full
```

### **Option 3: API Testing Only**
```bash
python main.py \
  --api "https://api.example.com" \
  --mode api_only
```

### **Option 4: Data Validation Only**
```bash
python main.py \
  --data "postgresql://localhost/mydb" \
  --mode data_only
```

### **Option 5: Multi-Module with Config**
```bash
python main.py --config config.yaml
```

Update [config.yaml](config.yaml):
```yaml
app:
  base_url: "https://myapp.com"
  api_url: "https://api.myapp.com"
  data_source: "postgresql://localhost/mydb"

mode: "full"  # Enable all three testing types
```
